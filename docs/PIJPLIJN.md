# Sitewerk-pijplijn

```text
brief
  → Bouwer (Feiten + Strategie + Kader → mix → rapport + werklijst → print/PDF)
  → Toetser  Toets 1
        afkeur → Naslag → Bouwer opnieuw (met afkeurzin)
        akkoord → Uitvoer (code-taken)
                 → (optioneel Atelier ná redesign-gate)

```
