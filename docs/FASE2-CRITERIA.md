# Fase 2 — wanneer software hard maken

Niet “na 10 runs”. Promoveer een regel naar schema/validator als:

1. Dezelfde les in **≥3 aparte runs** terugkomt met tag `kandidaat-code`, **of**
2. Toetser dezelfde blocker **≥2×** noemt,

**en** eigenaren bij Naslag-review (M7) expliciet ja zeggen tot automatisering.

Speelboeken blijven voor oordeel; code weigert alleen harde contractbreuken.
