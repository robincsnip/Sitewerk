# Playbook — Atelier (webdesign)

## Start alleen als alles waar is

1. Toets 1 akkoord  
2. Eigenaren redesign-gate ja (+ klantja indien extern)  
3. Site ontbreekt / coming-soon / aantoonbaar zwak (geen dunnere mock over sterke live site)  
4. Feitenvloer: naam, adres, tel, uren/diensten uit dossier — geen verzinsels  

## Flow

1. `design-brief.md` — stijl + rationale  
2. IA volgt SEO-hubbesluiten uit het rapport  
3. `werklijst-design.md`  
4. Bouw → preview  
5. Toets 2 op gecombineerde preview  

## In klantrapport

Atelier-zin alleen tonen als redesign-gate open mag. Anders weglaten.
